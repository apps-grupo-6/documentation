# Backend 
## Introduction / Introducción
### English
Each folder references a controller, there you will find out all sequence diagram that explains how each endpoint works and a .txt that could be used in https://sequencediagram.org/ for editing if needed.

### Español
Cada carpeta está referida a un controllador, donde dentro de ellas encontrarás un diagrama de secuencia que explica el funcionamiento de cada endpoint y un .txt que puede ser usado en https://sequencediagram.org/ para editar los diagramas en caso de ser necesario.
